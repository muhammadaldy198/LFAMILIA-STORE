## A.5 Komponen bersama yang menentukan mekanisme pop-up/edit di semua halaman

1. **AdminConfirmDialog** — dialog modal reka-ui di tengah layar (overlay hitam 70%, panel maks-w-md): judul (default "Konfirmasi tindakan"), pesan, tombol **"Batal"** (outline) + tombol konfirmasi (label per aksi, default "Lanjutkan"; varian destructive = merah). Inilah dialog konfirmasi standar untuk hapus/aksi berisiko.
2. **AdminSensitivePrompt** — konfirmasi kata sandi **Sheet dari kanan** (sm:max-w-sm): judul **"Konfirmasi kata sandi"**, deskripsi = alasan dari pemanggil (default "Tindakan ini memerlukan konfirmasi kata sandi."), field **"Kata sandi admin"** (password), tombol **"Batal"** / **"Lanjutkan"** ("Memeriksa…" saat proses). Muncul di tempat (in-place) saat aksi sensitif ditekan dan sesi belum terkonfirmasi (prop `adminPanel.sensitive_ready`; timeout sesi mengikuti `auth.password_timeout`, default 10800 detik). POST `/admin/password/confirm`. Error: "Kata sandi tidak cocok." / "Tidak dapat menghubungi server. Coba lagi." Halaman PasswordConfirm.vue adalah versi halaman penuhnya bila prompt in-place tidak dipakai.
3. **Pola Sheet (drawer kanan)** adalah mekanisme edit dominan di seluruh panel (produk, kategori, voucher, channel pembayaran, admin, tiket tidak — tiket inline). Lebar bervariasi sm:max-w-md sampai sm:max-w-5xl (editor produk).
4. **AdminMediaControl** (dipakai di editor produk/kategori/banner/berita/aset): pratinjau gambar (alt "Pratinjau gambar"), field berkas berlabel **"Gambar JPEG/PNG/WebP · maks. 5 MB"**, tombol **"Unggah gambar"** ("Mengunggah…"), tombol **"Hapus gambar"** (bila ada URL) → AdminConfirmDialog judul "Hapus gambar", pesan "Gambar ini akan dihapus dari toko. Tindakan ini tidak dapat dibatalkan.", konfirmasi "Hapus gambar".
5. **AdminResponsiveTable** — di layar kecil tabel berubah menjadi daftar record: hanya kolom yang listed di prop `mobile-columns` yang ditampilkan sebagai prioritas, dengan label dari header kolom; mode `scroll` (dipakai ruang kerja katalog) mempertahankan tabel asli yang bisa digeser mendatar.
6. **AdminSwitch** — saklar aktif/nonaktif standar (tanpa label bawaan; label ditulis halaman pemakai).
7. **Peta label status global** (`lib/orderStatus`): status pesanan — PENDING_PAYMENT "Menunggu pembayaran", PAID "Pembayaran diterima", PROCESSING "Sedang diproses", SUCCESS "Berhasil", FAILED "Pesanan gagal", EXPIRED "Pembayaran kedaluwarsa", CANCELLED "Pesanan dibatalkan", BLOCKED "Gagal diproses", REFUND/REFUNDED "Perlu pemeriksaan admin", fallback "Status sedang diperbarui". Label status pembayaran (`paymentStatusLabel`): PENDING/PENDING_PAYMENT "Menunggu pembayaran", CREATING "Menyiapkan pembayaran", UNKNOWN "Status belum dapat dipastikan", PAID/SETTLEMENT/CAPTURE/SUCCESS "Pembayaran diterima", REJECTED/DENIED/DENY "Pembayaran ditolak", FAILED "Pembayaran gagal", EXPIRED/EXPIRE "Pembayaran kedaluwarsa", CANCELLED/CANCEL "Pembayaran dibatalkan", REFUND/REFUNDED "Perlu pemeriksaan admin", fallback "Status pembayaran belum tersedia".

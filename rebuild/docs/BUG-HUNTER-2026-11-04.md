# Bug Hunter 4 Nov 2026 — CSRF and response-header ownership

## Scope
Repository + Cloudflare zone configuration only. No VPS edits, deploy, or production probes in this change. DOKU remains intentionally disabled; Google login PKCE and tracking throttle remain unchanged.

## Finding 1: stale CSRF on first action after login
The Laravel login flow rotates the session; an Inertia client-side transition may keep the original HTML `<meta name="csrf-token">`, while the browser already has a fresh `XSRF-TOKEN` cookie. The game-account save/delete and storefront checkout JSON requests previously sent `X-CSRF-TOKEN` from that old meta tag. Laravel checks `X-CSRF-TOKEN` before `X-XSRF-TOKEN`, so even attaching both is not safe if the meta header is stale.

The fixed flows send only `X-XSRF-TOKEN` from the current, URL-decoded browser cookie for each request, including immediately after authentication. No automatic retry of money-changing requests, no CSRF exemptions, and no session lifetime changes. Session cookies are sent with same-origin requests. Unit tests lock cookie-rotation behavior; PHP feature tests cover the login -> game-account save and quote flow.

## Finding 2: duplicate response security headers

**Single source of truth: `app/Http/Middleware/SecurityHeaders.php`.** On 4 Nov 2026, Cloudflare zone `lfamilia.com` was inspected (configuration only):
- Zone `security_header` / HSTS: **disabled** (`enabled=false`, `max_age=0`, `nosniff=false`).
- No zone-level `http_response_headers_transform` entrypoint ruleset; no response header-transform versions; no account-level response-header transform ruleset in the account ruleset list.
- Thus no Cloudflare header setting was modified: enabling one would create a second authority.

| Security header | Canonical value in Laravel |
| --- | --- |
| Strict-Transport-Security (HTTPS only) | `max-age=31536000; includeSubDomains` |
| X-Content-Type-Options | `nosniff` |
| X-Frame-Options | `DENY` |
| Referrer-Policy | `strict-origin-when-cross-origin` |
| Permissions-Policy | `camera=(), microphone=(), geolocation=(), payment=()` |
| Cross-Origin-Opener-Policy | `same-origin-allow-popups` |
| Cross-Origin-Resource-Policy | `same-site` |
| Content-Security-Policy | Laravel middleware: Turnstile + Cloudflare Web Analytics allowlist |

All values above are assigned by `SecurityHeaders.php`. Laravel's `HeaderBag::set` replaces its own value; it does **not** remove additional fields added by downstream Nginx. A live duplicate HSTS with `max-age=15552000` cannot be generated by the inspected Cloudflare configuration or the repository's middleware. The remaining origin Nginx/CloudPanel configuration is **not accessible in this task**. It is a suspected secondary writer, **not verified**.
